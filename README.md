# Quadro per D&A

Questa repository contiene solo la build web pubblica di Quadro. Il sorgente resta nel repository privato `dea-quadro-v2`.

Per leggere o modificare i dati serve un account abilitato dall’amministratore. I dati operativi e le credenziali non sono inclusi in questa pagina.

La build viene generata con `npm run build:live`; non usare qui il comando di pubblicazione della demo cifrata `quadro-demo`.
